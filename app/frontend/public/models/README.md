# VRM avatar

Place a VRM 0.x or VRM 1.0 humanoid avatar at:

`app/frontend/public/models/avatar.vrm`

The avatar must include humanoid arm, hand, and finger bone mappings. Facial
expressions are optional. When this file is absent, the application keeps using
`rigged_hand.glb` as a compatibility fallback.

## Bundled avatar

`avatar.vrm` is the Seed-san VRM 1.0 sample model by VirtualCast, Inc.
